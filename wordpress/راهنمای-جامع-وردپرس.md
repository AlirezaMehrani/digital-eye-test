## ۱. معرفی

این افزونه یک **هیرو ویدیوی اسکرولی سه‌بعدی** premium ایجاد می‌کند. تجربه به این شکل است:

- ویدیو **هرگز به‌صورت خودکار پخش نمی‌شود**
- موقعیت اسکرول کاربر **مستقیماً تایم‌لاین ویدیو را کنترل می‌کند**
- اسکرول به پایین → ویدیو به جلو می‌رود
- توقف اسکرول → ویدیو روی همان فریم متوقف می‌شود
- اسکرول به بالا → ویدیو به عقب برمی‌گردد
- حس حرکت در یک صحنه سه‌بعدی، نه تماشای یک ویدیو

## ۲. پیش‌نیازها

- وردپرس نسخه **۵.۶ یا بالاتر**
- PHP **۷.۴ یا بالاتر**
- یک ویدیوی MP4 با انکودینگ مناسب (کلیدفریم‌های مکرر — راهنمای انکودینگ در ادامه)
- دسترسی به **مدیریت رسانه** و **نصب افزونه**

> **نکته مهم درباره انکودینگ ویدیو:**
> ویدیوی شما باید **کلیدفریم‌های مکرر** داشته باشد (حدود ۳ کلیدفریم در ثانیه) تا اسکراب کردن نرم باشد. اگر ویدیوی شما فقط یک کلیدفریم دارد، اسکرول پرش خواهد کرد.
>
> برای انکودینگ با ffmpeg:
> ```bash
> ffmpeg -i input.mp4 -an \
>   -c:v libx264 -preset slow -crf 23 -pix_fmt yuv420p \
>   -g 8 -keyint_min 8 -sc_threshold 0 -movflags +faststart \
>   -vf scale=1280:720 output-desktop.mp4
> ```
>
> پارامترهای کلیدی:
> - `-g 8 -keyint_min 8` → کلیدفریم هر ۸ فریم (≈ ۳ کلیدفریم/ثانیه)
> - `-movflags +faststart` → moov atom در ابتدای فایل (seek سریع‌تر)
> - `-an` → حذف صدا (برای اسکراب نیاز به صدا نیست)
> - `-crf 23` → تعادل کیفیت و حجم

## مرحله ۱ — آپلود ویدیوها به وردپرس

### ۱.۱ — فایل‌های مورد نیاز

به چهار فایل نیاز دارید (فایل‌های آماده در پوشه `public/hero/` این پروژه موجود است):

| فایل | کاربرد | اندازه پیشنهادی |
|------|--------|------------------|
| `hero-desktop.mp4` | دسکتاپ (≥ ۸۶۱px) | 1280×720، ~۵MB |
| `hero-mobile.mp4` | موبایل (≤ ۸۶۰px) | 854×480، ~۲.۵MB |
| `hero-poster.jpg` | فریم اول — نمایش هنگام بارگذاری | ۱۶۰۰px عرض |
| (اختیاری) fallback image | تصویر جایگزین اگر ویدیو خراب شود | هر تصویر |

### ۱.۲ — آپلود

1. وارد **وردپرس → رسانه → افزودن** شوید
2. چهار فایل را آپلود کنید
3. روی هر فایل کلیک کنید و **URL کامل** را کپی کنید (مثلاً `https://yoursite.com/wp-content/uploads/2026/10/hero-desktop.mp4`)

> URLها را یادداشت کنید — در مرحله ۳ به آن‌ها نیاز دارید.

## مرحله ۲ — نصب افزونه

### ۲.۱ — روش FTP / مدیریت فایل (پیشنهادی)

1. پوشه `wordpress/hero-scroll-video/` را از این پروژه دانلود کنید
2. با FTP یا FileManager هاست، به مسیر `wp-content/plugins/` بروید
3. پوشه `hero-scroll-video` را کامل در آنجا آپلود کنید
4. ساختار نهایی:
   ```
   wp-content/plugins/hero-scroll-video/
   ├── hero-scroll-video.php
   ├── css/
   │   └── hero-scroll.css
   ├── js/
   │   └── hero-scroll.js
   └── assets/
   ```

### ۲.۲ — روش فایل ZIP

1. پوشه `hero-scroll-video` را به فایل `.zip` تبدیل کنید
2. وردپرس → **افزونه‌ها → افزودن → بارگذاری افزونه**
3. فایل ZIP را انتخاب و نصب کنید
4. افزونه را **فعال** کنید

### ۲.۳ — فعال‌سازی

پس از آپلود، به **افزونه‌ها → نصب‌شده** بروید و **Hero Scroll Video** را فعال کنید.

## مرحله ۳ — استفاده از شورت‌کد

شورت‌کد `[hero_scroll_video]` را در هر صفحه یا نوشته‌ای قرار دهید.

### ۳.۱ — مثال کامل

```html
[hero_scroll_video
  desktop_video="https://yoursite.com/wp-content/uploads/2026/10/hero-desktop.mp4"
  mobile_video="https://yoursite.com/wp-content/uploads/2026/10/hero-mobile.mp4"
  poster="https://yoursite.com/wp-content/uploads/2026/10/hero-poster.jpg"
  fallback="https://yoursite.com/wp-content/uploads/2026/10/hero-fallback.jpg"
  kicker="املاک لوکس و سرمایه‌گذاری"
  title="کشف خانه‌های<br>استثنایی"
  subtitle="املاک پریمیوم در بهترین موقعیت‌ها. خانه رویایی خود را با اطمینان پیدا کنید."
  cta_text="مشاهده املاک"
  cta_url="/properties"
  scroll_height="300vh"
]
```

### ۳.۲ — حداقل مورد نیاز

```html
[hero_scroll_video
  desktop_video="https://yoursite.com/wp-content/uploads/2026/10/hero-desktop.mp4"
  poster="https://yoursite.com/wp-content/uploads/2026/10/hero-poster.jpg"
]
```

> اگر `mobile_video` را ندهید، نسخه دسکتاپ برای موبایل هم استفاده می‌شود.

### ۳.۳ — قرار دادن در صفحه اصلی

1. **برگه‌ها → افزودن برگه** (یا ویرایش صفحه اصلی)
2. بلوک **HTML سفارشی** یا **کد کوتاه** (Shortcode Block) اضافه کنید
3. شورت‌کد بالا را جای‌گذاری کنید
4. صفحه را منتشر کنید

### ۳.۴ — قرار دادن با Page Builder

اگر از Elementor / Divi / WPBakery استفاده می‌کنید:

- **Elementor:** بلوک **Shortcode** را بکشید و شورت‌کد را قرار دهید
- **Divi:** بلوک **Code** را اضافه کنید
- **Gutenberg:** بلوک **Shortcode** یا **Custom HTML**

## مرحله ۴ — شخصی‌سازی متن و دکمه

تمام متن‌ها از طریق ویژگی‌های شورت‌کد قابل تغییر هستند:

| ویژگی | توضیح | پیش‌فرض |
|--------|--------|---------|
| `kicker` | برچسب کوچک بالای عنوان | Prime residential & investment property |
| `title` | عنوان اصلی (HTML مجاز، با `<br>`) | Discover Exceptional<br>Homes & Investments |
| `subtitle` | پاراگراف توضیحی | Premium properties in prime locations... |
| `cta_text` | متن دکمه (خالی = بدون دکمه) | Explore Properties |
| `cta_url` | لینک دکمه | # |
| `scroll_height` | ارتفاع منطقه اسکرول | 300vh |

### مثال فارسی

```html
[hero_scroll_video
  desktop_video="...mp4"
  poster="...jpg"
  kicker="مشاور املاک هوریزون"
  title="خانه‌ای بی‌نظیر<br>برای زندگی شما"
  subtitle="بیش از ۲۰ سال تجربه در بازار املاک لوکس. با ما بهترین تصمیم را بگیرید."
  cta_text="مشاوره رایگان"
  cta_url="/contact"
]
```

## مرحله ۵ — تنظیم رنگ‌ها و فونت

رنگ‌ها و ابعاد در فایل `css/hero-scroll.css` به‌صورت متغیر CSS تعریف شده‌اند. برای تغییر، فایل را ویرایش کنید:

```css
.hero-scroll-wrap {
  --hsv-navy-900: #0b1524;       /* رنگ پس‌زمینه تیره */
  --hsv-navy: #1a2b42;           /* رنگ دکمه */
  --hsv-navy-700: #22374f;       /* رنگ hover دکمه */
  --hsv-champagne: #b99b68;     /* رنگ طلایی تاکیدی */
  --hsv-champagne-soft: #e2d5bd;/* رنگ برچسب */
  --hsv-surface: #ffffff;       /* رنگ پس‌زمینه صفحه (برای fade پایین) */
  --hsv-container: 1240px;      /* حداکثر عرض محتوا */
  --hsv-gutter: clamp(20px, 4.5vw, 56px); /* padding کناری */
}
```

### تغییر فونت

فونت از قالب وردپرس شما به ارث می‌رسد. برای فونت اختصاصی، این خط را به `hero-scroll.css` اضافه کنید:

```css
.hero-scroll-content {
  font-family: 'Vazirmatn', 'IRANSans', sans-serif;
}
.hero-scroll-title {
  font-family: 'Vazirmatn', 'IRANSans', sans-serif;
}
```

## نکات بهینه‌سازی ویدیو

### انکودینگ برای اسکراب نرم

مهم‌ترین عامل در نرمی اسکراب، **کلیدفریم‌های مکرر** است:

```bash
# دسکتاپ (1280×720)
ffmpeg -i input.mp4 -an \
  -c:v libx264 -preset slow -crf 23 -tune film -pix_fmt yuv420p \
  -g 8 -keyint_min 8 -sc_threshold 0 -movflags +faststart \
  -vf scale=1280:720 hero-desktop.mp4

# موبایل (854×480)
ffmpeg -i input.mp4 -an \
  -c:v libx264 -preset slow -crf 24 -tune film -pix_fmt yuv420p \
  -g 8 -keyint_min 8 -sc_threshold 0 -movflags +faststart \
  -vf scale=854:480 hero-mobile.mp4

# پوستر (فریم اول)
ffmpeg -i input.mp4 -frames:v 1 -vf "scale=1600:-2" -q:v 4 hero-poster.jpg
```

### بررسی تعداد کلیدفریم

```bash
ffprobe -v error -select_streams v:0 -show_frames \
  -show_entries frame=key_frame -of csv hero-desktop.mp4 \
  | awk -F, '$2==1{c++} END{print "I-frames:", c}'
```

> برای ویدیوی ۱۰ ثانیه‌ای باید حدود **۳۰ کلیدفریم** ببینید (۳ کلیدفریم/ثانیه).

### بهینه‌سازی سرعت بارگذاری

- فایل دسکتاپ را زیر **۶MB** نگه دارید
- فایل موبایل را زیر **۳MB** نگه دارید
- حتماً `-movflags +faststart` استفاده کنید
- صدا را حذف کنید (`-an`)
- اگر هاست شما **CDN** دارد، ویدیوها از CDN سرو شوند

## رفع مشکل

### ویدیو اسکرول نمی‌کند / روی فریم اول می‌ماند

- **بررسی کنید** افزونه فعال است
- **بررسی کنید** URL ویدیو درست است (در مرورگر باز کنید)
- **بررسی کنید** کنسول مرورگر خطا ندارد (F12 → Console)
- مطمئن شوید `desktop_video` در شورت‌کد تنظیم شده

### اسکرول پرش دارد / تصویر یخ‌زده

- ویدیو کلیدفریم کافی ندارد → با ffmpeg با `-g 8` انکودینگ مجدد کنید
- فایل خیلی بزرگ است → رزولوشن یا CRF را کاهش دهید

### هیرو چسبانده نمی‌شود (sticky کار نمی‌کند)

- اگر قالب شما `body { overflow-x: hidden }` دارد، آن را به `overflow-x: clip` تغییر دهید:
  ```css
  body {
    overflow-x: hidden;
    overflow-x: clip;
  }
  ```
  `hidden` باعث می‌شود body یک scroll container شود و sticky را می‌شکند.

### ویدیو سیاه نمایش داده می‌شود

- `poster` را تنظیم کنید تا فریم اول قبل از بارگذاری ویدیو نمایش داده شود
- بررسی کنید فرمت MP4 / H.264 است

### روی موبایل کار نمی‌کند

- ویژگی `playsinline` در کد افزونه موجود است (برای iOS)
- مطمئن شوید `mobile_video` تنظیم شده
- اگر موبایل ضعیف است، `scroll_height` را به `250vh` کاهش دهید

### متن روی ویدیو خوانا نیست

- overlay در `hero-scroll.css` قابل تنظیم است (opacity را افزایش دهید)
- یا `text-shadow` عنوان را قوی‌تر کنید

## ساختار فایل‌ها

```
hero-scroll-video/
├── hero-scroll-video.php    ← افزونه اصلی + شورت‌کد
├── css/
│   └── hero-scroll.css       ← تمام استایل‌ها (با متغیرهای قابل تنظیم)
├── js/
│   └── hero-scroll.js        ← موتور اسکراب (vanilla JS، بدون jQuery)
└── assets/                   ← (اختیاری) جای آپلود ویدیوها
```

### شورت‌کد — تمام ویژگی‌ها

```
[hero_scroll_video
  desktop_video=""     ← URL ویدیوی دسکتاپ (الزامی)
  mobile_video=""      ← URL ویدیوی موبایل (اختیاری)
  poster=""            ← URL تصویر فریم اول (توصیه‌شده)
  fallback=""          ← URL تصویر جایگزین (اختیاری)
  kicker=""            ← برچسب بالای عنوان
  title=""             ← عنوان اصلی (HTML مجاز)
  subtitle=""          ← پاراگراف توضیحی
  cta_text=""          ← متن دکمه (خالی = بدون دکمه)
  cta_url=""           ← لینک دکمه
  scroll_height="300vh" ← ارتفاع منطقه اسکرول
]
```

## خلاصه سریع

1. ویدیوها را با کلیدفریم مکرر انکودینگ کنید
2. چهار فایل را در رسانه وردپرس آپلود کنید
3. افزونه را در `wp-content/plugins/` آپلود و فعال کنید
4. شورت‌کد `[hero_scroll_video ...]` را در صفحه اصلی قرار دهید
5. URLها و متن‌ها را در شورت‌کد تنظیم کنید
6. رنگ‌ها را در `css/hero-scroll.css` شخصی کنید
